# Student Marks Analysis Project

## Project Overview

This project analyzes student marks data using Python libraries like Pandas, Matplotlib, and Seaborn.

The program:
- Reads student marks from a CSV file
- Cleans invalid or missing data
- Categorizes students based on marks ranges
- Counts students in each category
- Visualizes the distribution using:
  - Matplotlib Bar Chart
  - Seaborn Count Plot

---

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- OpenPyXL
